# 낙상 Temporal 모델 녹화영상 비교 (2026-09-14)

## 결론

금요일 학습 모델 `fall_temporal_baseline_same_split_20260910.pt`를 기준 모델로
유지한다. 후보 모델은 학습 조건과 같은 pose 입력에서도 Recall과 FP가 모두
불리하므로 승격하지 않는다.

초기 `imgsz=320` 비교는 학습 feature 생성 조건인 `imgsz=640`과 달랐다.
따라서 최종 판단은 640 재평가 결과만 사용하며, 기존 320 결과는 평가 조건
불일치를 보여주는 참고 자료로만 보존한다.

## 평가 조건

- 원본 영상: 낙상 라벨 16개, 정상 보행 7개
- Pose 모델: `models/fall/yolov8n-pose.pt`
- Pose 입력: `imgsz=640`, confidence `0.35`
- Temporal 임계값: 0.5
- 장치: Jetson CUDA
- 실행 순서: 영상마다 baseline-first/candidate-first 교차
- 출력: 영상 단위 판정, 최대 30개 프레임 균등 샘플링

## 입력 크기 영향

초기 320 평가에서 가림 낙상 3개의 유효 pose는 6, 2, 2개였고 모두 FN이었다.
학습 조건과 같은 640/0.35에서는 유효 pose가 17, 8, 8개로 증가했고 세 영상
모두 베이스라인 TP가 됐다. 원본 영상 해상도 문제나 재촬영 사유가 아니라
평가 전처리 설정 불일치였다.

## 구간 클립 재평가

정제 후 베이스라인 FN 4개를 낙상 전환 구간으로 잘라 같은 640 조건에서
재평가했다.

| 장면 | 전환 구간 | 베이스라인 | 후보 |
| --- | --- | ---: | ---: |
| `140519_backward_fall` | 5.5~10.5초 | FN 0.0024 | FN 0.0055 |
| `141112_backward_fall` | 16~23초 | TP 0.8179 | FN 0.00003 |
| `141753_right_fall` | 0.5~3.5초 | FN 0.1644 | TP 0.8532 |
| `141827_right_fall` | 63~80초 | TP 0.5959 | TP 0.7478 |

`141112`와 `141827`은 전체 영상의 정적 자세가 전환 신호를 희석한 평가 방식
문제다. `140519`와 `141753`은 구간을 잘라도 베이스라인이 놓쳐 실제
positive hard-case로 분류한다.

## 재촬영 대상

- `20260910_141230_left_fall.mp4`: 9.8초 동안 앉기와 앞으로 숙이기만 보이며
  바닥으로 넘어지는 전환이 없다.
- `20260910_141722_right_fall.mp4`: 9.5초 동안 앉기·일어서기·다시 앉기만
  보이며 명확한 낙상 전환이 없다.

재촬영 시 낙상 전 정상 자세 3~5초, 낙상 전환, 바닥 자세 3~5초를 한 영상에
연속으로 포함한다. 카메라 원본 해상도는 현재 수준을 유지해도 되며 평가와
feature 추출의 `imgsz=640`을 동일하게 맞춘다.

## 2026-09-14 재촬영 검증

기존에 제외한 좌·우 낙상 영상을 카메라 RTSP 원본으로 다시 촬영했다.

| 원본 | 길이 | 해상도/FPS | 이벤트 구간 |
| --- | ---: | --- | --- |
| `left_fall_standing_raw_120s.mp4` | 119.973초 | 1920×1080, 약 29.99 FPS | 18~38초 |
| `right_fall_standing_raw_120s.mp4` | 119.973초 | 1920×1080, 약 29.99 FPS | 12~34초 |

두 원본은 전체 디코딩 검사를 오류 없이 통과했다. 시각 검수에서는 정상 자세에서
바닥 자세로 이동하는 전환과 이후 자세 변화가 확인됐다. 다만 실제 급격한 측면
낙상보다는 손·무릎을 사용해 비교적 천천히 내려가는 동작에 가깝고, 바닥 자세에서
신체 일부가 화면 하단 경계에 가까워지는 구간이 있다.

학습과 동일한 `imgsz=640`, confidence `0.35`, temporal 임계값 `0.5`로 평가했다.

| 입력 | 베이스라인 | 후보 | pose 프레임(베이스라인) |
| --- | ---: | ---: | ---: |
| 왼쪽 이벤트 18~38초 | TP 1.000000 | TP 1.000000 | 28 |
| 오른쪽 이벤트 12~34초 | TP 0.999996 | TP 0.999999 | 18 |
| 왼쪽 원본 120초 | TP 1.000000 | TP 0.999992 | 17 |
| 오른쪽 원본 120초 | TP 1.000000 | TP 0.999533 | 18 |

재촬영 영상은 이벤트 구간과 120초 전체 입력에서 두 모델 모두 검출했다. 따라서
이 두 영상은 현재 모델의 실패 사례가 아니며, 이 결과만으로 재학습을 시작하지
않는다. 기존 베이스라인을 유지하고, 실제 hard-case인 `140519`와 `141753`을
보강할 독립 촬영 데이터를 추가 확보한 뒤 재학습 여부를 결정한다.
