# 전임자 인수인계 자료 분류 기준

기준일: 2026-09-04

## 목적

`AIoT개발팀_오세영_인수인계자료`는 설계 문서, 소스코드, 모델 실험 결과, 장비 선정·설치 자료가 함께 들어 있는 프로젝트 원본 보관소다.
현재 운영 문서의 단일 기준으로 사용하지 않고, 아래 분류 기준에 따라 정부과제 증빙과 현재 운영 문서를 연결한다.

## 상태 정의

| 상태 | 의미 | 처리 방법 |
|---|---|---|
| 현재 기준 | 현재 코드·운영 절차와 일치 | 최신 문서에 연결 |
| 증빙 | 요구사항·설계·시험·실증의 근거 | 원본 보존, 제출 목록화 |
| 참고 | 제조사 프로토콜·교육·환경 설명 | Device Service·런북에 필요한 부분만 반영 |
| 레거시 | 과거 직접 제어·구형 구조 | 삭제하지 않고 현재 운영 기준에서 제외 |
| 보류 | 장치·기능·자료가 미확정 또는 미검증 | 실제 검증 전 운영 기능으로 표현하지 않음 |

## 최상위 폴더 분류

| 경로 | 주요 내용 | 분류 | 현재 반영 방향 |
|---|---|---|---|
| 루트 `0~7` 문서 | 플랫폼·디바이스·시연 설명 | 참고·증빙 | EdgeX 기준으로 재작성하고 원본은 이력 보존 |
| `Nvidia Jetson 관련 파일` | Jetson 설치·사용 매뉴얼 | 참고 | Jetson 런북의 환경 참고자료로 연결 |
| `smartpole` | 과거 통합 AI·직접 장치 제어 코드 | 레거시 | 모델·과거 시연 이력만 참고 |
| `디바이스 연동 소스코드` | 스피커·전광판·경광등 직접 제어 | 레거시·참고 | 제조사 변환 로직을 Device Service와 대조 |
| `엣지 플랫폼` | 구형 SEdge-Platform·KETI 연동 | 증빙·레거시 | 초기 설계 이력으로 보존, 현재 구조의 기준으로 사용하지 않음 |
| `연동 디바이스` | 설치·교체·카탈로그·견적·프로토콜 | 증빙·참고 | 장비 인벤토리·프로토콜 근거로 연결 |
| `이상행동 검출 모델 구현` | 학습 코드·모델·결과·영상 | 증빙·참고 | 후보 모델 평가 후 운영 모델만 승격 |

## 현재 프로젝트와의 연결

```text
전임자 설계·프로토콜 자료
        ↓
현재 이벤트 계약·Action 정책
        ↓
EdgeX Core Command
        ↓
장치별 Device Service
        ↓
실제 장치 UAT 및 증빙
```

전임자 코드의 직접 HTTP·Socket 호출은 운영 경로가 아니라 Device Service 내부 변환 로직의 참고자료로 본다.

## 정부과제 증빙으로 보존할 자료

- 과제 요구사항과 서비스 시나리오
- 플랫폼 구조도와 초기 설계 변경 이력
- 장비 선정 근거, 카탈로그, 견적, 설치 자료
- 제조사 API·프로토콜 원문
- 모델 학습 설정, 결과 이미지, 성능 비교표
- 시연 영상과 현장 화면
- 시험 로그, EdgeX 명령 결과, 장치 상태 기록
- 작성자·작성일·버전·파일 출처

## 현재 기준에서 제외할 표현

- 실제 장치 UAT가 없는데 “제어 완료”라고 표현하는 것
- Direct 호출 코드를 EdgeX 운영 경로로 설명하는 것
- 실험 데이터 성능을 현장 정확도로 표현하는 것
- 한 폴에 한 장치만 존재한다고 가정하는 것
- 문서에 계정·비밀번호·토큰을 그대로 기록하는 것

## 장치별 현재 상태

| 장치 | 자료 상태 | 현재 프로젝트 상태 | 문서 표현 |
|---|---|---|---|
| CCTV | API·설치자료 있음 | Jetson 입력으로 사용 | 연결·스트림 상태를 별도 기록 |
| 전광판 | 다빛 프로토콜·M30 자료 있음 | EdgeX 명령 경로 검증 완료, 물리 표시 육안 확인 필요 | EdgeX 라우팅 검증 완료 |
| 스피커 | Inter-M API·카탈로그 있음 | 실제 연결 불가 | API·dry-run 검증, 실제 UAT 미완료 |
| 사이렌/경광등 | Qlight·GPIO 자료 있음 | 실제 장치 없음 | 설계·보류 기능 |
| DID | HDMI·pywebview 자료 있음 | 운영 장치 미확정 | 보류 기능 |

## 보안 주의

원본 문서와 과거 코드에 내부 IP와 인증정보가 포함된 항목이 확인된다. 이 값은 운영 문서나 외부 제출본에 복사하지 않으며, 담당자 변경 시 교체하고 제출본에서는 마스킹한다.
