## 현재 상태

- crop-pose는 실제 운영 전환 전 POC 단계
- 운영 기본 경로는 full-frame 유지
- 실제 Jetson 성능 측정과 녹화 낙상 영상 비교가 남아 있음
- 학습 산출물 생성 전까지는 Compose 재생성 금지
- 2026-09-09 현재 `fall_temporal_same_split`은 partial/smoke 산출물만 확인됨
- 기존 `fall_temporal_hybrid_all_cached`는 준비 점검은 통과하지만 baseline과 dataset version이 달라 비교 판정은 hold
- Compose 정적 readiness는 14개 중 13개 통과. 유일한 실패는 ARM64 호스트에서
  기본 `docker-compose.yml`의 일부 EdgeX 이미지가 amd64 전용일 수 있다는 경고이며,
  Jetson에서는 `docker-compose.jetson.yml`을 사용해야 한다는 기존 정책과 일치함
- 최신 컨테이너 상태 확인: feature extraction 실행 중, train cache 11,420/12,688,
  validation cache 840/2,720. 후속 RF·temporal 학습 프로세스는 추출기 종료를 대기 중
- 10초 후 재확인 시 extractor PID 118460은 `Sl` 상태로 유지되고 train cache가
  11,422개로 증가했으며 validation cache는 840개로 유지됨
- 후속 확인에서 extractor는 `Rl` 상태로 유지되고 train cache 11,424개까지
  증가했다. 로그의 `[train 11426/12688]` 항목으로 추출 진행을 재확인했다.
