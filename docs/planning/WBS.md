| 1 | 현재 후보·모델·설정 고정 및 기존 증거 연결 — 30분 | 소스/모델 해시와 활성 설정 명시. 과거 보존본 시험과 현재 후보 시험을 구분하고 이미 통과한 항목은 근거를 재사용 |
| 2 | NVENC 포함/제외 및 재연결·종료 경계 대조 — 최대 2시간 | 같은 입력·후보·관측 조건에서 한 번에 한 조건만 변경. 최초 오류/정상 복구/종료를 구분. 시험용 EOS·강제 중지로 생긴 오류를 원 CUDA700 재현으로 세지 않음 |
| 3 | 현재 후보의 단일 입력 통합 확인 중 빠진 항목 — 2시간 30분 | [종료 판정표](VIDEO_INFERENCE_CONTRACT.md#p51-closeout-v075)에 모델별 completed/no_target/unavailable, 프레임·시각·DB/송출 대응, 단절 후 오래된 결과 차단 근거 연결. 미충족 항목은 실패 또는 미검증으로 기록 |
| 4 | 결과 판정·다음 행동 확정 — 1시간 | 통과/실패/미검증 표, 원인 후보를 줄인 근거, 필요한 최소 수정 또는 추가로 필요한 증거를 보고. I34/I07 잔여 시 P5.1 IN_PROGRESS·운영 전환 보류 유지 |

2단계에서 원인 단서가 잡히면 3단계 배정을 해당 결함의 최소 수정·회귀에 사용하고,
남은 통합 확인은 미실행으로 기록한다. 고정 시간에 맞추려고 검증 범위를 생략하거나 합격 처리하지 않는다.

**조사 중단·재계획 기준:** 새 결함·코드 변경·추가 가설을 구분할 수 있는 조건 없이 같은 시험을 반복하지 않는다.
2시간 내 CUDA700이 재현되지 않거나 원인 범위가 좁혀지지 않으면 해당 비교를 종료하고,
기존 최초 로그·최소 실행 방법·환경/입력 해시·성공/실패 조건을 외부 기술 검토 가능한 자료로 묶는다.
I34는 계속 OPEN이며 다음 조사 가설과 필요한 관측을 정한 뒤 다시 착수한다.
그 사이 GPU 안정화에 의존하지 않는 P5.2 평가 영상·정답 목록 준비는 할 수 있으나,
P5.1 선행 조건이나 P5.2 연동 합격을 충족했다고 표시하지 않는다. 자료 공유/외부 문의는 별도 지시가 있을 때 수행한다.

후속 순서: P5.1 필수 조건 충족 → P5.2~P5.5 모델별 검증 → 선행 조건을 충족한 P3/P4 장치·센서 연동
→ P6 통합·다중 카메라·장시간 시험. 장비/외부 기준 대기는 기존 의존성을 따른다.
진행 보고는 **이번에 통과한 것 / 남은 문제 / 바로 다음 한 가지**를 먼저 제시한다.
