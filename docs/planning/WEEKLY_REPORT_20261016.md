### 2. 다중 카메라

- 10-13 두 입력 시험은 **단일 입력용 maxBatch1 엔진에 batch2를 요청**해 기동에 실패했다. 이 실행에서 정상적인 두 채널 FPS/지연을 얻지 못했으므로 성능 검증 완료로 집계하지 않는다.
- 소스 수에 따른 mux/추론 batch 구성, 출력 queue 제한은 기존 구현을 재사용한다. 외부 예제는 배치 조건과 느린 입력 검증 항목 참고용으로 활용하며 코드를 통째로 이식하지 않았다.
- 다음 시험은 실제 엔진 해시와 profile을 연결해 요청 batch를 대조한 뒤 진행한다. 기존 batch1~2 후보가 존재해도 최신 960 입력 후보와 동일 품질·속도라고 가정하지 않는다.
- 최신 단일 입력도 실제 추론 중앙값이 약 14.84회/초다. 2/4입력에서 카메라별 15회/초를 달성할지는 미검증이다. 녹화 재생 부하 시험은 실제 4대의 네트워크·재접속 인수 시험과 구분한다.

- 시험 후 동일 운영 AI와 이미지를 복구했고 다른 4개 대상 서비스는 유지했다. 최신 CPU 회귀 종료 후 30초 관측은 **29.96FPS / 실제 추론 14.98회/초**, 재시작 증가 0이었다. 단기 회복 확인으로 장시간 안정성을 대신하지 않는다.
- 최신 낙상 엔진/판정 후보는 운영 모델로 교체하지 않았다. 기존 운영 준비 자료는 재사용하되 10-07 등 이전 주의 준비 실적을 이번 주 신규 작업으로 중복 집계하지 않았다.
