# 개발 도구 자료

이 디렉터리는 애플리케이션 실행과 직접 관련 없는 개발 도구 원본 자료를 보관합니다.

## `agents/`

Codex skill을 생성할 때 사용한 에이전트 원본 문서입니다.

- 앱 실행, Docker 배포, 테스트에는 포함되지 않습니다.
- Codex가 자동으로 발견하는 실제 skill 경로는 `.codex/skills/`입니다.
- `.codex/skills/*/references/source-agent.md`가 이 원본 문서를 상세 참고 자료로 연결합니다.

에이전트 원본을 수정할 때는 연결된 skill의 요약 설명과 참조 링크도 함께 확인합니다.
