# 배포 준비 계획 (2026-07-27)

## 목표

운영 배포에 필요한 플랫폼 안정성, 재현 가능한 검증, 롤백, 모니터링을 자동 확인한다. 낙상 모델은 별도 품질 게이트를 통과한 경우에만 운영 승격한다.

## 현재 판정 기준

- 플랫폼 배포 게이트: 구성/시크릿/컨테이너/헬스/운영 점검 통과
- 모델 품질 게이트: 고정 평가 세트에서 recall >= 0.80, precision >= 0.70, 데이터 누수 없음
- 운영 승격 전제: shadow 또는 pilot 결과와 롤백 절차가 문서화되고 재현 가능해야 함

## 실행 순서

1. 기존 배포 readiness 및 운영 점검을 실행해 기준선 기록
2. 고정 모델 평가 결과를 품질 게이트 입력으로 연결하고, 기준 미달이면 명시적으로 실패
3. 롤백 명령과 모니터링 확인 항목을 운영 런북에 반영
4. 전체 테스트와 구성 검증을 다시 실행

## 승인/보류 규칙

- 모든 플랫폼 게이트 통과 + 모델 품질 게이트 통과: 배포 후보
- 플랫폼 게이트 통과 + 모델 품질 게이트 미달: 플랫폼만 배포 가능, 모델 운영 승격 보류
- 런타임 오류, 프레임 드롭, 파일 디스크립터 증가 또는 롤백 검증 실패: 배포 보류

## 롤백 원칙

낙상 보조 모델/검증 기능은 환경 변수로 비활성화하고 AI 엔진만 재시작한다. 롤백 뒤 운영 점검을 실행해 알람·스트림·이벤트 경로가 정상인지 확인한다.
